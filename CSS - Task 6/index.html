Combinators

Combinators are used to select elements by their relationship with other elements.

1. Descendant Combinator (Space)

The descendant combinator selects all elements inside a specified element.

Paragraph 2 inside section and div.

2. Child Combinator (>)

The child combinator selects only the direct children of a specified element.

Direct child paragraph.

Nested paragraph. It is not a direct child of div.

3. Adjacent Sibling Combinator (+)

The adjacent sibling combinator selects the element that comes immediately after another element.

Heading

Second paragraph.

4. General Sibling Combinator (~)

The general sibling combinator selects all matching siblings that come after a specified element.

Summary

Space = all descendants

> = direct children

+ = immediately next sibling

~ = all following matching siblings
