1. Descendant Combinator (Space)

It selects all elements inside another element.

Example: div p

Working: It selects all p tags inside div.

2. Child Combinator (>)

It selects only direct child elements.

Example: div > p

Working: It selects only direct p tags inside div.

3. Adjacent Sibling Combinator (+)

It selects the element just after another element.

Example: h1 + p

Working: It selects the p tag just after h1.

4. General Sibling Combinator (~)

It selects all matching siblings after an element.

Example: h1 ~ p

Working: It selects all p tags after h1 with the same parent.

Conclusion

I learned four types of CSS Combinators and their working.
