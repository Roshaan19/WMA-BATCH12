CSS Box Model

This assignment shows how content, padding, border and margin work in the CSS Box Model.

1. Width Examples

Example 1: Content Box

Width is 200px and padding is 20px.

Content Width: 200px

Example 2: Different Padding

Width is 200px and left and right padding is 30px.

Content Width: 200px

Example 3: Border Box

Width is 200px including padding and border.

Total Width: 200px

2. Height Examples

Example 4: Content Box

Height is 100px and padding is 20px.

Content Height: 100px

Example 5: Different Padding

Height is 100px with 20px top and bottom padding.

Content Height: 100px

Example 6: Border Box

Height is 150px including padding and border.

Total Height: 150px

3. Summary

  • Content: Area where text or images appear.
  • Padding: Space inside the border.
  • Border: Line around the content and padding.
  • Margin: Space outside the border.
  • Content-box: Padding and border are added to width and height.
  • Border-box: Padding and border are included in width and height.
