1. Introduction

The CSS Box Model is an important concept in CSS. It explains how every HTML element is displayed as a rectangular box. It consists of four main components: Content, Padding, Border, and Margin.

2. Components of the CSS Box Model

1. Content
Content is the actual area where text, images, or other elements appear.

2. Padding
Padding is the space between the content and the border. It creates space inside an element.

3. Border
Border is the line surrounding the content and padding.

4. Margin
Margin is the space outside the border. It creates distance between elements.

3. Width Examples

In this section, I used different width, padding, and border values to observe how the total width of an element changes.

Example 1: Content-box

Width: 200px

Border: 5px (left and right)
Box-sizing: content-box

Calculation:

Example 3: Border-box

Width: 200px
Padding: 20px (left and right)
Border: 5px (left and right)
Box-sizing: border-box

Calculation:
200px is the total width, including padding and border.
Content Width = 200 - 40 - 10 = 150px
Total Width: 200px

5. Difference Between Content-box and Border-box

Content-box:
In content-box, the width and height properties apply only to the content. Padding and border are added outside the declared dimensions.

Border-box:
In border-box, the declared width and height include content, padding, and border. The total size remains fixed.
